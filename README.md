# RAG_AI_Agents

This repository is an AI RAG system ready for production deployment.

  This repo is fully built on Python.
  Streamlit is used for the frontend.
  Qdrant is the vector database which can be run locally.
  Inngest is used for the orchestration and observability.
  LlamaIndex is the tool the model will use to ingest PDFs.
  Anthropic API is used for the LLM.
